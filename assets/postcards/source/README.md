# Masters

Kept out of Godot's import path by .gdignore. The shipped files in the folder
above are cut from these, so re-running a tool never loses a generation.

* `tokyo_ink.png`, `paris_ink.png` — Season One's drawings.
  Paris was generated in colour because the black-and-white run ran out of
  budget. Season One is ink and paper throughout, so the game treats it as a
  grey drawing; replace this file when a black-and-white version exists and
  nothing else needs changing.
* `*_sunset.ogv`, `*_monet.ogv` — the looping films that went with the painted
  postcards these replaced. Retired rather than deleted: a landscape colour
  film behind a tall ink drawing is two different pictures.
